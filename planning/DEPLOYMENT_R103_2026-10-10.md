# Blank deployment r103 — 10 October 2026

Application 0.25.0-dev, schema 25. This blank development prerelease includes the r99–r102 save-recovery and single-user performance work, plus comments for 117 VBA functions/subroutines. It contains no reports, contributors, groups or directory members.

## Use

Download `Swift_NAVFIT_Deployment_2026-10-10-r103-blank.accdb` from the GitHub prerelease, make a working copy, and open it in trusted desktop Microsoft Access. Setup opens automatically; enter your command and contributor, then create a summary group and reports. Existing populated databases should be transferred into a separate blank template through `scripts/upgrade-workspace.ps1` with an explicit `-TemplatePath`; do not replace them with this empty file.

## Changes since r98

- Members opens directly from current reports. Ordinary navigation and cell saves create no historical comparison snapshots; explicit proposal/history workflows retain their baselines and conflict checks.
- Failed comparison cells remain pending for retry or explicit discard. Successful cells are removed individually, with attribution and close guards preserved.
- Cached row display state and targeted averages/editor refreshes reduce repeated queries. Save-time checks still verify current report state.
- Live validation and recovery run when values change rather than scanning unchanged drafts on every timer tick.
- Removed the duplicate comparison roster control and redundant group navigation/refresh paths.
- Added comments explaining navigation, caching, recovery and transactional saves.

## Verification and limitations

The exact release file compiled and its normal startup opened setup. All 48 user-data tables are empty; AppMetadata retains version/schema only. Scratch-copy tests verify live/historical member workflows, pending-cell recovery and event-driven validation/checkpoints. See [artifact verification](DEPLOYMENT_R103_VERIFICATION.json) and [r102 behavioral evidence](EFFICIENCY_R102_VERIFICATION.json).

Synthetic r102 scale testing covered 25/50/100-member groups for all three report types: row moves 5–7 ms, cell saves 93–110 ms and group opens 0.64–1.09 s. Editor opening remains 2.44–4.01 s and is the next performance target. These are local COM timings, not guarantees on other computers; see [method and results](SCALE_R102_2026-10-10.md).

Full printing/fit, NAVFIT98A round-trip acceptance, physical accessibility/scaling, Runtime/x86 and target-computer dependency checks remain outstanding. One contributor uses the authoritative file at a time; separate copies do not synchronize. The existing r98 and earlier releases remain available.
