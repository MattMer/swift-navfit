# r24 native-review priority fixes

Version 0.22.0-ux-preview, schema 21. Earlier artifacts and existing workspaces are preserved. The synthetic demo and empty workspace are separate; do not transfer existing data into the seeded demo.

## Changes

1. Report-list capture tolerates absent scrollbars and column headings, reads numeric report identities only, and restores selection/top report without blocking editing. A focused create/save/single-result-search/reopen fixture complements the existing scrolled-list tests.
2. My Work combines pending assignments, the current contributor's ordered-route steps, ready local approvals and related unresolved comment roots. Requesters can see stale routes that need restarting. Future steps are excluded. Comments are related threads, not assigned tasks. Routes/comments have no invented due dates. Assignment decisions are disabled when stale, archived, approved or assigned to another contributor; transaction guards remain. Open selected work reaches the exact route or root thread. Resolve/reopen refreshes pending work, with completed history still available. Dashboard counts use the same queue scope.
3. Reports/group/comparison title and filter spacing is corrected; Save remains visibly labeled; read-only guidance spans the editor content area, including locked Review/History. Report/comment lists use readable headings and revision numbers. Comments, snippets, recovery and import selection gain the shared navigation/header. Closing snippets returns to Resources; comments return to their actual report rather than an unrelated editor. Native help and the workspace guide describe the unified inbox.

The native check also exposed a nonnumeric folder-filter entry path. The selector is restricted to listed folders, and its change handler retains the prior filter with guidance if supplied an invalid value.

## Native evidence and limits

Computer-use checks used a disposable seeded copy of the r24 blank, not the deliverable or an existing user workspace. At desktop width all six synthetic work rows were visible. The stale Avery assignment showed revision 2, cancellation/reassignment guidance, and disabled Accept/Return. A Casey comment opened its selected root in the correct report context. Robin's current ordered route opened with step 1 selected; accepting it advanced to Robin as the next contributor, disabled the former contributor's decisions and reduced that contributor's pending inbox from six to five.

A single-result Casey search reopened through the native list, with Save draft visible. At a captured 1366x768 Access window the settled editor retained visible bottom actions and vertical field scrolling; My Work retained its action area and displayed selected-item details separately from condensed columns. The desktop window capture was 1920x1032 on the 1920x1080 display because the Windows taskbar remained visible. Windows scaling was not changed or verified. These checks do not establish screen-reader acceptance, full keyboard order or every native workflow. Coordinate targeting after window resizing was unreliable and caused an invalid filter input; the resulting folder validation path is guarded, but automation limitations must not be reported as complete accessibility evidence.
