The newest posted note is selected automatically. Contributor and posting time appear beside each note preview. Write a report note and Continue selected draft note are distinct actions; the composer labels the text area and identifies the posting contributor. Post note, Save draft and close, and Discard draft retain the existing attributed-note/checkpoint services. Open comments and replies links directly to report feedback.

The Review page gives Comments and replies prominence and explains its distinction from review-route steps. The comment screen labels the conversation list, full conversation, and message editor. Comment previews identify contributor, posting time and saved revision. The newest conversation opens automatically; Refresh preserves an unfinished message and its selected conversation. Write new comment and Reply to selected choose the explicit posting mode, and the send button says Post new comment or Post reply accordingly. Resolve/reopen/reply actions reflect the selected conversation state; archived reports remain read-only. Reopening the same report preserves the composer, and opening another report is blocked until an unsent comment is posted or cleared. My Work respects this guard. Comment threads, replies, authors, revision links and resolution events are unchanged; comments remain separate from official narratives and working notes.

Each summary-group ITA cell has two native conditional-format rules evaluated against that row's PriorITA. Higher numeric values use green, lower values use yellow. Equal, absent, NOB, nonnumeric and out-of-range comparisons keep the normal appearance. The underlying ITA, prior ITA, promotion, saved report fields and revision history are not changed. Rules follow bound row values and the existing grid refresh after trait edits, including each row in a continuous form.
