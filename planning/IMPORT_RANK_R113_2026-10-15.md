# r113 — automatic 20xx import years and rank filters

## Changes

- Removed century-prefix controls from structured PDF import, NAVFIT group import, legacy full-report import and returned-file reconciliation. These UI paths always use 2000/20 for two-digit years. Native decoding without a supplied century defaults to 2000. PDF six-digit dates always expand with 20; full-year dates remain explicit values. Invalid calendar dates still fail validation, with no OS-dependent year pivot. Low-level native decoding still accepts an explicitly supplied legacy 1900 argument for compatibility; it is not exposed as an import choice.
- Added **Filter by rank/rate** to both Add report to summary group and Create reports from command members. Choose All ranks/rates, an available paygrade (E6 includes IT1 and YN1), a specific rank/rate, or Unentered.
- Filters show active members only. Single-report filtering clears the previous selected identity and copied fields, retaining the entered report dates. Batch filtering clears selection and invalidates the preview/Apply state. Filtering creates no reports or profile edits.
- Updated keyboard tab order and in-app guidance. Group type/paygrade, identity, duplicate-period and transactional guards remain in place.
