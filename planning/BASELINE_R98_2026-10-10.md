# Deployment baseline r98 — 10 October 2026

This baseline freezes the current implementation after the user-confirmed r96 comparison-save repair and r97 RUAD import/refresh. It adds no new narrative-fit or returned-group capability. Application version remains **0.25.0-dev**, schema **25**. The release is a development prerelease, not production acceptance.

## Deployment files

- `Swift_NAVFIT_Deployment_2026-10-10-r98-blank.accdb`: fresh source build, empty command/report/group/member workspace; normal startup opens Setup.
- `Swift_NAVFIT_Deployment_2026-10-10-r98-DEMO.accdb`: the same app with newly generated synthetic EVAL, CHIEFEVAL and FITREP reports, groups, contributors, review/recovery examples and two complete dummy RUAD profiles; normal startup opens Overview.
- `Swift_NAVFIT_Baseline_2026-10-10-r98.zip`: both files, source, build/test scripts, guides and artifact verification.

Existing author-edited and r97 test files are preserved locally and are not release assets. Local test fixtures, supplied RUAD CSV, NAVFIT98A executable/reference databases and supplied PDFs are excluded from Git and the deployment package. Access databases are distributed as private GitHub release assets rather than Git source objects.

## Current implementation

The native workspace includes Overview, searchable Reports, summary groups with editable member/comparison tables, defaults for new reports, review, history, My Work, Resources and Settings/Help. Reports use compact Admin data and official block sections, SSN, checkbox selections, date pickers, trait guidance, ITA/group arithmetic, narratives, saved revisions, automatic recovery, notes and local review/approval.

Report and group workflows retain saved-revision guards, atomic updates and applicable undo/provenance. The comparison save repair retains the Report write cursor while linking its new revision; the user confirmed the reported 3218/3420 failure is resolved. Approval reopening and queued cell saving remain in place.

Command directory records expose all 35 RUAD columns and prior-evaluation information. RUAD import/refresh provides choose/preview/apply/results, explicit identity matching, vacancy skips, manual-value conflict preservation, source baselines and stale/duplicate guards. It does not automatically remove absent members or provide batch import undo.

NAVFIT adapters support canonical field mapping including Block 28, retained native values, report/group export, selected native-group import and single-report three-way returned-file reconciliation. Structured PDF import and cited live validation are available within their documented support scope. Neither establishes complete policy compliance.

## Verification and limits

The packaged files are compiled and checked for normal startup. Installed source modules are compared with current source. Fresh synthetic data are used for deployment regression tests; their results and SHA-256 hashes are recorded in `BASELINE_R98_VERIFICATION.json` and the package manifest. This is targeted artifact verification, not a claim that every historical suite or every target environment has been retested.

The local NAVFIT98A 2.2.0.332 reference harness now uses `NAVFIT98A/Data/NF98A_Dte.accdb`; the previous `D:\NF98A_Dte.accdb` path was a harness setup error. Its actual controllers successfully load/save all three synthetic report types and execute page-two data drawing offscreen. These checks are **not** full Swift-export round-trip acceptance, native GUI journeys, printer-driver validation or exact printed-fit certification.
