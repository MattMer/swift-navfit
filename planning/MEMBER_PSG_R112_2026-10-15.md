# r112 — automatic PSG and report-driven member identity

## Completed

- Reporting senior, historical baseline and exclusion confirmation save on change. Removed the separate Save selection/calculation button. Loading saved selections writes nothing; changing the senior/baseline resets exclusion confirmation.
- Checkbox: “These reports have not yet been included in the selected BOL totals.” This confirmation remains explicit; it is never guessed or checked automatically.
- Group footer shows reporting senior and PSG RSCA together, including estimate/partial labels. Numeric traits saved in the native grid immediately refresh the displayed PSG. No duplicate initial footer calculation.
- Applying senior details to the reports remains deliberate, then refreshes PSG. Calculations continue to use saved revisions and do not certify Navy compliance.
- PDF draft creation supplies extracted official name, rank and SSN before directory linking. It no longer creates a placeholder first and leaves the final report attached to it.
- Directory matching first uses full SSN. Without an SSN match, a unique normalized name can identify an active profile only when SSNs do not conflict. Ambiguous names do not auto-merge. Name normalization removes case, spaces, commas and periods; no fuzzy matching or inferred identity.
- Confirmed report links enrich missing directory SSNs and report-name/rank details, including RUAD profiles. Older or undated reports fill blanks but do not replace information supplied by a later dated linked report. Other RUAD fields/source data and existing report fields remain intact. Unchanged identity edits do not rewrite profiles.
- Opening the command directory repairs only known PDF-import placeholder links, retaining import receipts, report values and historical evaluations. Unused placeholders are archived, not deleted; profiles with history are retained. Repairs are logged and idempotent.
- Imported saved reports appear in member history directly; there is no duplicate PriorEvaluation copy. Previous-evaluation columns select reports ending before the current report starts. Same-date alternatives remain ambiguous rather than guessed.
