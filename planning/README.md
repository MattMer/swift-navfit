# Planning and development notes

These are the project's working notes: the priority backlog, design decisions,
investigation findings and verification history. They record how Swift NAVFIT
was built and why, and are kept for reviewers and contributors.

They are not user documentation, and older notes can describe behaviour that
later work changed. For how to use Swift NAVFIT, see the
[user guide](../docs/Swift_NAVFIT_User_Guide.md). For the current state of the
code, see [PROJECT_STATE.md](../PROJECT_STATE.md) and the
[technical README](../TECHNICAL_README.md).

Start with the [priority backlog](PRIORITY_BACKLOG.md).
